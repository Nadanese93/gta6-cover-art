Neon Skyline Studio turns your photos into GTA 6-style cover art: six multi-panel layouts, five sunset and neon grades, and a real comic-print render pipeline (posterize, Sobel ink outlines, gradient-map grade, halftone dots, grain and vignette). Crop and position each photo per panel, edit the caption, set the star heat meter and badge ribbon, then export a PNG in 1080×1080, 1080×1350, 1920×1080 or 1080×1920. Fully offline — no network, no uploads.

## Run it

```sh
node serve.ts --port 8080
# then open http://localhost:8080
```
